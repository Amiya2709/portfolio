House ruleshow the playbook becomes habit

A playbook only works if the team runs it without me.

Rule 01

The brief carries the rules

Every brief template has the hook rules, a don’t-say list, filming specs and example scripts. Creators get the playbook without having to read it.

Rule 02

Three hooks or it isn’t a set

Scripts come back as 1A, 1B, 1C on a fixed body and CTA. Every set is a test.

Rule 03

Nothing reaches the client unchecked

Every cut passes the pre-flight checklist below before it leaves the team.

Rule 04

Claims stay as approved

No code, no consent, no posting. The registry is linked to the ad tracker, so a gap shows up straight away.

Rule 05

Status lives on the board

Not in DMs. Client status is tracked apart from internal status, so everyone sees the same truth.

Rule 06

Refresh before it fades

New hooks, new creators and new angles every month, before results drop.

Rule 07

Fridays are for fixing

The creative team’s protected admin day, to clean up systems instead of firefighting.

Rule 08

Write it down

SOPs and recorded walkthroughs, so nothing depends on one person, including me.
